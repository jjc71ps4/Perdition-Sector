# Perdition Sector 0.2.0-beta.1

Current player-build snapshot, November 20, 2026. This is a beta test build.

- Name/gender-only new-game setup with the approved background and audio handoff.
- Jug's preset applies automatically; Side Aim initialization fix included.
- Mouse5 momentary flashlight, Mouse4 Side Aim; ECO fire-mode key unbound.
- Five-minute radio recovery and deterministic Perdition intro selection.
- Approved panoramic NVG mask with cyan-blue white-phosphor color. Experimental
  grain is removed; ReShade is not required.
- Compact, aspect-correct splash launcher.
- Confirmed subway poster repair covers all 17 deleted frames, including GNN
  and Slocum's Joe frames. Faust confirmed the current repairs work in game.
- Installer downloads this exact snapshot from this release, checks SHA-256
  hashes, creates the separate compatible game instance and offers optional ENB.

Known issues: unresolved grass rendering, NVG precipitation visibility and
museum floor/precombine damage. Sixteen deleted posters outside the edited
subway interiors remain recorded for later precombine-aware cleanup.

Download the installer ZIP, extract it, and run `PerditionSetup.exe`. The large
numbered payload assets download automatically. A Steam account owning Fallout
4 and all six gameplay DLCs is required. No Bethesda game depots are bundled.

Source/fixture checks do not replace installation and gameplay testing on a
different PC. The existing development installation is not reinstalled.

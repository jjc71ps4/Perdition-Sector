# NT4 Desert Hex Black and Splinter update 0.1.6

Desert Hex Black (OMOD MK18_Deluxe.esp:000047, MSWP 000067) now
uses the existing plain black NT4 material. Splinter (OMOD 00005C,
MSWP 00006A) receives a new rifle-matched Splinter diffuse and material.
Both source KAC suppressor mesh materials receive these substitutions.

Desert Hex Black 2 Electric Boogaloo is a separate paint option (OMOD
00004B, MSWP 000068). Its Black Hex pattern is preserved byte-for-byte.
All other records and all existing textures and mesh alignment are preserved.

Splinter uses the same actual receiver UV patch as the validated Urban sample,
with identical source BGSM UV settings (offset 0, scale 1). The 0.1.5 physical
surface metric and projection are reused. A versioned bake/validation snapshot
is generated by prepare_splinter.py. Source image pixels retain their proportions
and rifle-scale footprint. Outer-body aspect error is under 0.242%, measured on
4,589 body triangles; 1,002 flat cap triangles also pass. Native front and reverse
renders inspect the exact saved diffuse. Bevels and the underside closure are
outside those flat/body metric bounds.

The update installs one BC7 sRGB diffuse with 13 mip levels, one BGSM, and the
existing ESL-flagged NT4 patch. Two material swap records each change only their
two KAC destination paths. The patch header description is updated. No OMOD
gameplay fields or masters change; no new records are added. Fifteen other
patch records remain exact, including Electric Boogaloo.

Run prepare_splinter.py, then bake_splinter.py and validate_splinter.py inside
the saved replacement Blender project, starting Blender in C:\workspace.
Run stage_update.py then install_update.py with game/MO2 closed. The installation
receipt stores before/after hashes and backups. rollback_update.py restores
the prior ESP and removes only the two new Splinter files after hash checks.

Installed locally for in-game review. Publication has not been requested.

# Perdition Sector - Beta

Perdition Sector is Faust's tactical horror shooter built inside Fallout 4,
with high-lethality combat, light discipline, randomized HVT objectives and New Game Plus.

## Install on another PC

1. Download [Setup 0.2.5-beta.1](https://github.com/jjc71ps4/Perdition-Sector/releases/download/updates-2026.11.23.1/Perdition_Sector_Installer_v0.2.5-beta.1_Beta.zip).
2. Extract the complete ZIP and run `PerditionSetup.exe`.
3. Choose a new Perdition folder. The Perdition package downloads automatically from GitHub.
4. If Fallout 4 is already downgraded, keep **Use existing downgraded Fallout 4**
   selected and browse to its folder. Setup requires **1.10.163 and all six DLCs**;
   an incompatible or missing game prompts for a valid folder before installation.
5. Alternatively choose the Steam-download option and sign into the owning account.
6. Choose resolution and optional ENB, then install. Launch with `Launch Perdition Sector.cmd`.

Setup downloads the unchanged 34 GB beta base, then automatically applies the
ordered radio, weapon, urban repair and intro-menu updates. Existing installations download only missing updates. Existing-game
mode skips Steam game/DLC downloads and uses that game folder directly.
Setup installs the matching F4SE 0.6.23 and required root files, keeping backups.

Already have Perdition installed? Close the game and MO2, extract the new setup
ZIP and run **Update existing Perdition.cmd**. Choose the Perdition folder containing
ModOrganizer.exe. This downloads only missing updates and installs the current
updater for future use. Personal resolution, unrelated settings and saves remain.

# Confirmed revisions in Setup 0.2.3-beta.1

The unchanged beta-2026.11.20.1 base package is followed by the published radio
patch and the 67.6 MB confirmed-revisions update. The latter contains the aligned
NT4 replacement, RUTex tone correction, Black/BLK finish, original FDE finish,
two attachment-record repairs and the accepted North End visibility patch.

The updater migrates only the FO4ME mod/plugin activation entries and six approved
distance settings. It retains personal resolution, unrelated INI settings and saves.
It backs up assets and profile settings before applying a combined transaction.
Unexpected custom file contents or distance values stop that transaction.

The accepted values are exterior mesh fades 3500/2000, interior 2600/1950,
object fade 15 and mesh fade scalar 1. Four redundant mod entries are disabled;
their replacement providers and dependent active plugins are retained.

The RUTex replacement and tone correction are confirmed working in-game by the
author. The new black finish and complete fresh-PC installation need user testing.
Fixture verification does not claim a complete authenticated Steam installation.
